# samples/

Test audio clips for the pipeline.

**Only royalty-free / Creative Commons / self-recorded clips belong here.**
Do **not** commit copyrighted songs — riffscribe (the tool) is fine to publish,
but distributing copyrighted audio is not.

Good sources:
- Your own guitar recordings.
- [GuitarSet](https://zenodo.org/records/3371780) excerpts (MIT license) — solo
  acoustic guitar with ground-truth string/fret annotations, ideal for evaluation.
- Creative Commons clips from Freesound, etc. (check the specific license).
